# Сайт Елизаветы Кравец

Одностраничный сайт без сборки и внешних сервисов. Шрифты и изображения находятся в папке `assets/`.

## Локальный запуск

Из корня репозитория выполните:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Затем откройте `http://localhost:4173`. Для публикации достаточно разместить `index.html`, `styles.css` и папку `assets/` на любом статическом хостинге.

## Что осталось заполнить

- В разделе результатов заменить показатели `ХХХ` на подтверждённые цифры и добавить реальные скриншоты вместо обозначенных мест.
- В разделе проектов добавить отдельные карточки для каждого кейса: название, сферу, срок, старт, задачи, проделанную работу, результаты и при необходимости ссылку на аккаунт. Сейчас раскрывающиеся карточки показывают структуру будущих кейсов.
- Добавить услуги и стоимость, а также реальные контакты для связи.

Все тексты и блоки находятся в `index.html`. Цвета, сетка, адаптивность и анимация лепестков — в `styles.css`. Анимация отключается, если в системе пользователя включено уменьшение движения.

## Проверка

node --test tests/site.test.mjs
