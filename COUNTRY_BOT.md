# Telegram-бот «Угадай страну»

Кооперативная викторина с доступом ровно для двух Telegram-аккаунтов: вашего и девушки. Любые другие пользователи не могут запускать игру, отвечать или смотреть счёт. Игроки угадывают страну исключительно по картинке флага — бот загружает изображения с FlagCDN (`flagcdn.com`). Первый правильный ответ приносит очко. Вопросы идут без повторов: первые 5 раундов — распространённые флаги, раунды 6–15 — менее очевидные страны, далее — в том числе флаги территорий. В комплекте 244 актуальные записи ISO (страны и территории) с русскими названиями и столицами; изображения флагов загружаются с FlagCDN. Названия и столицы основаны на CountryInfo (MIT, Copyright (c) 2018 Porimol Chandro); русские названия — на locale-файле i18n-iso-countries (MIT, Copyright (c) 2016 widdix GmbH). Тексты лицензий и атрибуция включены в `data/LICENSES.md`. Для изображений при игре нужен интернет.

## Запуск

1. В Telegram откройте **@BotFather**, выполните `/newbot` и сохраните выданный токен. Не публикуйте токен и не добавляйте его в репозиторий.
2. Каждый из вас отдельно напишите боту `/myid` и скопируйте свой числовой Telegram ID. Эта служебная команда отвечает только на ID самого вызвавшего пользователя; остальные команды и игровые сообщения для чужих аккаунтов игнорируются.
3. Для первичного получения ID запустите бота без `ALLOWED_USER_IDS` (в этом режиме работает только `/myid`, игра недоступна). После того как оба ID получены, остановите процесс и запустите заново с `ALLOWED_USER_IDS='ваш_ID,ID_девушки'`.
4. Добавьте бота в общий чат только вдвоём. Для обычных ответов в группе откройте @BotFather → `/setprivacy` → выберите бота → **Disable**, затем удалите и добавьте бота в группу заново. Доступ проверяется по Telegram ID участника, а не по названию чата.

Запуск на компьютере или сервере с Python 3.10+:

```bash
export TELEGRAM_BOT_TOKEN='ваш-токен-от-BotFather'
# Сначала узнать ID (пока не задавайте ALLOWED_USER_IDS):
python3 country_bot.py
# Затем остановить Ctrl+C и запустить с двумя реальными числовыми ID:
export ALLOWED_USER_IDS='123456789,987654321'
python3 country_bot.py
```

Процесс должен оставаться запущенным, пока вы играете. Это long polling, webhook или открытый порт не нужны. Не запускайте несколько копий бота с одним токеном одновременно.

## Управление

В стартовом меню Telegram показывает «Игра вдвоём» и «Одиночная игра». После начала вопроса меню выбора режима больше не появляется: остаются только кнопки управления раундом. В одиночном режиме доступны уровни: начальный, средний, продвинутый и все флаги; флаги выбранного уровня не повторяются; режим «Все флаги» идёт по этапам: знакомые флаги → остальные страны → редкие флаги территорий. Каждый вопрос показывает один флаг и четыре варианта-страны на кнопках; нужно выбрать название показанной страны за 15 секунд. По истечении времени ответ раскрывается и появляется следующий вопрос. Одиночная тренировка не добавляет очки в общий счёт. Нажатия обрабатываются как callback-запросы, поэтому кнопки работают и в группах с включённым privacy mode. Чтобы бот также видел текстовые ответы в группе, выключите privacy mode у @BotFather. Команды ниже можно вводить вручную.

## Команды

- `/newgame` — начать или сбросить игру вдвоём;
- `/solo` — открыть меню одиночной игры и выбрать уровень изучения флагов;
- `/hint` — подсказки усиливаются на одном флаге: длина названия → первая буква → первые две → первые три → столица. Всего 5 подсказок на игру, общий лимит на чат; на новом флаге последовательность начинается заново.
- `/score` — посмотреть счёт;
- `/next` — показать ответ и перейти дальше;
- `/stop` — завершить игру;
- `/help` — справка.

Данные игры хранятся в памяти процесса и сбрасываются при перезапуске бота. Чтобы добавить страну, допишите запись с ISO-кодом, названием, столицей и русским названием в `data/countries.json`.
