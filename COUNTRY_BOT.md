# Telegram-бот «Угадай страну»

Кооперативная викторина с доступом ровно для двух Telegram-аккаунтов: вашего и девушки. Любые другие пользователи не могут запускать игру, отвечать или смотреть счёт. Игроки угадывают страну исключительно по картинке флага — бот загружает изображения с FlagCDN (`flagcdn.com`). Первый правильный ответ приносит очко. Вопросы идут без повторов: первые 5 раундов — распространённые флаги, раунды 6–15 — менее очевидные страны, далее — в том числе флаги территорий. В комплекте 246 записей ISO с названиями и столицами; часть названий указана по-английски. Для изображений при игре нужен интернет.

## Запуск

1. В Telegram откройте **@BotFather**, выполните `/newbot` и сохраните выданный токен. Не публикуйте токен и не добавляйте его в репозиторий.
2. Каждый из вас отдельно напишите боту `/myid` и скопируйте свой числовой Telegram ID. Эта служебная команда отвечает только на ID самого вызвавшего пользователя; остальные команды и игровые сообщения для чужих аккаунтов игнорируются.
3. Для первичного получения ID запустите бота без `ALLOWED_USER_IDS` (в этом режиме работает только `/myid`, игра недоступна). После того как оба ID получены, остановите процесс и запустите заново с `ALLOWED_USER_IDS='ваш_ID,ID_девушки'`.
4. Добавьте бота в общий чат только вдвоём. Для обычных ответов в группе откройте @BotFather → `/setprivacy` → выберите бота → **Disable**, затем удалите и добавьте бота в группу заново. Доступ проверяется по Telegram ID участника, а не по названию чата.

Запуск на компьютере или сервере с Python 3.10+:

```bash
export TELEGRAM_BOT_TOKEN='ваш-токен-от-BotFather'
# Сначала узнать ID (пока не задавайте ALLOWED_USER_IDS):
python3 country_bot.py
# Затем остановить Ctrl+C и запустить с двумя реальными числовыми ID:
export ALLOWED_USER_IDS='123456789,987654321'
python3 country_bot.py
```

Процесс должен оставаться запущенным, пока вы играете. Это long polling, webhook или открытый порт не нужны. Не запускайте несколько копий бота с одним токеном одновременно.

## Команды

- `/newgame` — начать или сбросить игру;
- `/score` — посмотреть счёт;
- `/next` — показать ответ и перейти дальше;
- `/stop` — завершить игру;
- `/help` — справка.

Данные игры хранятся в памяти процесса и сбрасываются при перезапуске бота. Чтобы добавить вопросы, допишите записи в `COUNTRIES` в `country_bot.py`.
